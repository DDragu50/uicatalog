## Core concepts

- **Component contracts**<br/>Each README.md file states what the component does, includes options, callbacks, errors, and accessibility. Every requirement has a test case.
- **Structured configuration**<br/>Easy-to-write and understand configurations simplify customization, ensure consistency, and enable reliable AI-assisted development.
- **Single entry point**<br/>A unified public API simplifies component integration, reduces implementation dependencies, and ensures consistent access to component capabilities.
- **Any framework, no build**<br/>The same files in React, Vue, Svelte or a plain page.
